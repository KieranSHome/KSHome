# Kiwiii website logos

Approved logo assets live in the top-level `assets/` directory. Use the supplied artwork without redrawing or altering it.

| Site or page | Approved asset | Usage |
|---|---|---|
| Kiwiii.Stream | `assets/Kiwiii Home Green Tech Logo.png` | Homepage header, footer and favicon |
| Kiwiii.Stream/blog | `assets/Kiwiii Blog Kiwi Emblem Logo.png` | Blog header and favicon |
| Jellyfin.Kiwiii.Stream | `assets/Kiwiii Stream Kiwi Logo.png` | Media service identity |
| Kiwiii.Stream/broke | `assets/Kiwiii Broke Neon Bird Logo.png` | Broke dashboard identity |
| Kiwiii.Stream/Projects | `assets/Kiwiii Projects Logo with Hammer Emblem.png` | Projects page identity |

Keep the filenames and capitalization consistent. When an asset changes, update the corresponding page header, favicon and metadata references together.
